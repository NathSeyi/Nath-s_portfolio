Employee Payroll Analysis Using Microsoft Excel

Project Overview

This project analyses employee payroll data using Microsoft Excel to evaluate salary distribution, overtime payments, total payroll costs, and net salary across departments.

Tools Used

* Microsoft Excel
* PivotTables
* PivotCharts
* Excel formulas
* Dashboard visualisation

Business Questions

* What is the organisation’s total monthly salary expenditure?
* Which department has the highest payroll cost?
* Which department records the highest overtime payments?
* What is the total net salary across all departments?
* How is payroll expenditure distributed across departments?

Key Findings

* Total Monthly Salary: ₦3,670,000
* Total Overtime Pay: ₦260,000
* Total Payroll Cost: ₦3,930,000
* Total Net Salary: ₦3,563,000
* IT recorded the highest payroll cost at ₦1,490,000.
* HR recorded the lowest payroll cost at ₦625,000.

Business Recommendations

* Review payroll expenditure across departments.
* Monitor overtime payments, particularly in IT.
* Improve departmental payroll budgeting.
* Use regular payroll reports to support management decisions.

Project Files

* Employee_Payroll_Analysis.xlsx
* Employee_Payroll_Analysis_Report.docx
* Payroll_Dashboard.png

Conclusion

This project demonstrates how Microsoft Excel can be used to transform raw payroll data into meaningful insights that support financial monitoring and business decision-making.
